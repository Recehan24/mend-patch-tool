mend is one command-line tool that applies the edits AI models write — unified diffs (often with wrong line numbers), SEARCH/REPLACE blocks, V4A patches and text-editor tool calls as JSON — to a tree of text files. It finds the lines an edit names even when the model drifted their whitespace or indentation, and it changes every file or none. Built by an AI agent for make.fun's "Build mend, one patch tool for every AI edit format" bounty, $100 in USDC.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```
